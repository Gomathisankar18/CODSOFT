# Task 4 - Sales Prediction using Python 

## Objective
To build a Machine Learning regression model to predict product sales based on advertising spending.

## Dataset
Advertising Dataset (TV, Radio, Newspaper vs Sales)

## Steps Performed
- Imported libraries
- Loaded dataset
- Checked missing values
- Performed EDA (histogram, scatter plots, correlation heatmap)
- Selected features (TV, Radio, Newspaper)
- Train-test split
- Trained Linear Regression model
- Predicted sales values
- Evaluated using MAE, RMSE, and R² score
- Visualized Actual vs Predicted Sales

## Model Used
- Linear Regression

## Result
Model predicts sales with good accuracy.
