# Task 3 - Iris Flower Classification

## Objective
Build a machine learning model to classify Iris flowers into:
- Setosa
- Versicolor
- Virginica

## Dataset
Iris dataset from sklearn.

## Steps Performed
- Loaded dataset
- Data analysis (info, null check)
- Visualization (species count)
- Train-test split
- Logistic Regression model
- Accuracy evaluation
- Confusion Matrix

## Result
Model achieved high accuracy in predicting Iris species.
